# Phase 0 - MVP Scope Sign-off (Citizens Lens)

## In scope (PRD S27, build these)
1. Search in everyday language (primary entry)
2. Direct answers: short answer first
3. Read More (progressive disclosure)
4. Original provision text with source block
5. Explore by situation/topic (12 situations)
6. Learn: 2 paths (Understand the Constitution + Real-Life Situations)
7. I Need Help Now (secondary placement, info only)
8. Save (localStorage) + Share (copy local URL)
9. Source/version info on every answer

## Out of scope (to Phase 8 backlog, do not build now)
Myth vs Constitution, full glossary (seed 15 terms only), What Changed?,
court interpretation, other laws, audio, Nigerian-language, classroom tools,
accounts/backend, cloud hosting, SEO/sitemap.

## Trust acceptance criteria (every screen must pass)
- [ ] Explanation visually distinct from constitution quote and metadata
- [ ] Every answer links to a real provision ID with version + status
- [ ] Qualifications/exceptions preserved, no absolute-rights claims
- [ ] Current vs proposed vs historical clearly labeled
- [ ] Disclaimer present: constitutional information, not legal advice
- [ ] Neutral wording, no advocacy language

## Metrics to log locally from day one (PRD S29)
Searches, no-result queries (top 20 reviewed weekly), read-more rate,
provisions viewed, lesson completion, saves, shares, repeat visits.

## 12 Explore situations (v1)
Arrest & detention, personal liberty, freedom of expression, peaceful assembly,
privacy, property, fair hearing, citizenship, elections & political participation,
government powers, courts & justice, duties of citizens.

## Sign-off
Reply "approved" to lock this scope. Any feature outside the In-scope list
requires an explicit scope-change note before building.
